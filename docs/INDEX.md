# Vulcan Skills & Agents Reference

## Skills

- **[vulcan](../skills/vulcan.md)** — Multi-agent feature forge orchestrator - ships features from spec to PR

## Agents

- **[architect](../agents/architect.md)** — Reads spec, explores project, writes implementation plan
- **[api](../agents/api.md)** — Implements HTTP/GraphQL endpoints and integration layer
- **[backend](../agents/backend.md)** — Implements server logic, services, business rules
- **[db](../agents/db.md)** — Writes schema migrations and query layer updates
- **[frontend](../agents/frontend.md)** — Implements UI components, pages, client-side interactions
- **[reviewer](../agents/reviewer.md)** — Reviews expert work against spec success criteria
- **[security](../agents/security.md)** — Scans changed files for security vulnerabilities
- **[shipper](../agents/shipper.md)** — Creates branch, commits, pushes, opens PR
