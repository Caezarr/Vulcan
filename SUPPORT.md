# Support

## Bugs, feature requests, questions

Open a [GitHub Issue](https://github.com/Caezarr/Vulcan/issues). Say which agent, skill or template is affected, and include:

- **Bug reports:** the feature spec (redacted), session id, and the relevant `workspace/` files (`state.md`, `messages.jsonl`). Run `node scripts/validate-messages.mjs workspace/messages.jsonl` first; its output often pinpoints the failing phase.
- **Feature requests:** the use case and expected behaviour.
- **Questions:** check existing issues first.

## Security vulnerabilities

Use [GitHub Security Advisories](https://github.com/Caezarr/Vulcan/security/advisories/new). See [SECURITY.md](SECURITY.md). Never open a public issue for a security finding.

## Scope

Best-effort support, no SLA.
